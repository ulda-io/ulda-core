# ULDA Pack Comparison

This document describes the local comparison script for ULDA package formats.
See `ULDA_PACK_POLICY.md` for the current pack/version policy.

`compactV1` is the ULDA 1.0 standard/default runtime pack. `simpleSig` is the
legacy v1 package format and remains supported explicitly with
`sign.pack: "simpleSig"`.

`compactV1` uses a smaller and more flexible bit-level header. The header
carries age/index, reserves backup-related fields, and keeps the body layout
compatible with the current origin and witness package bodies. The low-level
header utility can transport backup data, but canonical ULDA v1 packages do
not set those fields and define no backup semantics.

The comparison script measures package sizes and local operation speed across
`simpleSig` and canonical `compactV1`. In compactV1, absent age means `0n`;
present age is a 4-byte unsigned big-endian integer. 8-byte age is not part of
the compactV1 runtime and should be handled by a future pack or version if
needed. The script also runs each pack through `hex`, `base64`, and `bytes`
export formats.

Run:

```bash
npm run compare:packs
npm run compare:packs -- --iterations 1000
```

The benchmark is local and intentionally simple. Small differences can be noise
from the JavaScript runtime, the machine, or concurrent system load. Do not
treat these numbers as protocol decisions.

The script does not print package contents, private origin blocks, witness
bytes, or raw descriptors. It reports only lengths, timings, pack id, mode, `N`,
age byte width, and export format.
