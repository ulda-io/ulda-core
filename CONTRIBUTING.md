# Contributing to ULDA Core

Thank you for your interest in ULDA Core.

## Current contribution policy

ULDA Core uses a source-available community license together with separate
commercial licensing. The project license is not a contributor agreement.

Until suitable contributor terms have been approved and published, the project
cannot accept third-party pull requests, patches, code, test vectors, or
documentation changes. Please do not submit copyrightable implementation
material. Unsolicited pull requests may be closed without review.

Issue reports, reproducible bug descriptions, questions, and factual feedback
are welcome. Do not include confidential, proprietary, or third-party material
that you are not authorized to disclose.

Forking and modifying the repository does not grant rights beyond those stated
in [LICENSE.md](LICENSE.md).

## Security reports

Do not report suspected vulnerabilities in a public issue. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md).

## Future contributions

If code contributions are opened later, the maintainers will publish the
applicable contributor agreement or other contribution terms before accepting
them. Opening an issue, pull request, or discussion does not by itself grant
ULDA permission to relicense submitted material.

Please keep all public discussion respectful and focused on the project.
